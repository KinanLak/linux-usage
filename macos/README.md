# Linux Usage for macOS

Native SwiftUI menu bar port of the GNOME extension. Same popup (overview → provider detail, Session/Weekly toggle, refresh / preferences) and the same preferences, built from SwiftUI primitives.

Requires macOS 14+. No Xcode project: a Swift package plus a Makefile that assembles the `.app`.

## Build & run

```bash
cd macos
make app        # universal build/Linux Usage.app (ad-hoc signed)
make run        # build, quit the running copy, launch
make install    # copy to ~/Applications and launch
make zip        # build/linux-usage-macos.zip
make snapshot   # print the provider snapshot JSON, like `helper.js snapshot --pretty`
```

`make ARCHS=arm64 …` skips the x86_64 slice for faster local builds.

The binary also has the helper CLI built in:

```bash
"build/Linux Usage.app/Contents/MacOS/LinuxUsage" snapshot [--pretty]
"build/Linux Usage.app/Contents/MacOS/LinuxUsage" probe claude
```

### UI work without credentials

```bash
make dev ARGS="--sample --open-popup"      # sample data, popup opened
make dev ARGS="--sample --open-preferences"
```

The dev build is a separate bundle (`….dev` bundle id and defaults domain). `--open-popup` opens the real popup even when the menu bar item is behind the notch or a menu bar manager. These flags only exist in debug builds.

## Layout

| Path | Role | GNOME counterpart |
| --- | --- | --- |
| `Sources/LinuxUsage/Providers/` | Claude and Codex fetchers, credentials, cache and backoff, registry | `src/helper/` |
| `Sources/LinuxUsage/Model/` | Snapshot types (`contracts/snapshot.schema.json`), catalog, settings | `providers.json`, gschema |
| `Sources/LinuxUsage/App/UsageStore.swift` | Refresh loop and popup state | `ui/popup.ts` (indicator), `services/helper_client.ts` |
| `Sources/LinuxUsage/UI/` | Popup, quota bar, preferences | `ui/popup.ts`, `stylesheet.css`, `prefs-widget/prefs.ts` |

## Differences from the GNOME extension

- **No helper process or D-Bus.** Providers are fetched in-process with `URLSession`, concurrently, with the same backoff, stale-cache fallback and messages. The cache lives in `~/Library/Caches/io.github.kinanlak.linux-usage/`.
- **Claude credentials:** Claude Code on macOS stores its login in the Keychain (`Claude Code-credentials`), read through `/usr/bin/security` after the `~/.claude/.credentials.json` files.
- **CLIProxyAPI server** (extra credential source, also the last fallback of Automatic): for accounts that only live on a remote CLIProxyAPI, set its URL and management key in Preferences → Credentials. The app lists the accounts (`GET /v0/management/auth-files`) and has the proxy run the usage request itself (`POST /v0/management/api-call` with `$TOKEN$`), so Claude and Codex tokens never reach the Mac. The proxy needs `remote-management.allow-remote: true` and a secret key. Prefer a dedicated key for the Mac: CLIProxyAPI also accepts a `MANAGEMENT_PASSWORD` environment variable (a second management key you can revoke on its own). The key is stored in the login Keychain (`io.github.kinanlak.linux-usage.cli-proxy`) through `/usr/bin/security`, so rebuilds of the ad-hoc signed app don't trigger Keychain prompts. It grants full management of the proxy, so treat it like a password.
- **Settings** use the gschema key names in `UserDefaults` (`defaults read io.github.kinanlak.linux-usage`).
- **Menu bar percentage** (Preferences → Menu bar, also on GNOME as Preferences → Top bar, with the same logos in `src/extension/icons/`): the most used provider's usage, or one provider's, in the window picked by the popup's Session/Weekly toggle.
- **Popup:** an `NSStatusItem` with an AppKit panel rather than a SwiftUI `MenuBarExtra` (which rendered as a square, untinted window on macOS 26+). The panel is an `NSGlassEffectView` on macOS 26+ (menu material before), keeps its top edge under the item, and closes on a click elsewhere or Escape. Buttons and quota cards use Liquid Glass on macOS 26+; clickable elements get a pointing-hand cursor.
- **Menu bar item:** the logo of the provider whose percentage is shown (Claude and Codex marks from [CodexBar](https://github.com/steipete/CodexBar), MIT), the status symbol otherwise. Left click toggles the popup; right click (or Control-click) opens a menu with About, Preferences and Quit.
- **Additions macOS needs:** Open at login (Preferences → General), Quit and About (right-click menu; Quit also in Preferences and ⌘Q in the popup), ⌘R to refresh and ⌘, for preferences in the popup, and a refresh after the Mac wakes.

The provider logic is a line-by-line port of `src/helper/`. When it changes there, mirror the change in `Sources/LinuxUsage/Providers/`.
